# AnywhereMMD

VRChatのアバターに、利用者自身の見た目で踊るMMD映像を追加するPC向けツールです。
**音源・ダンス・カメラ・アバターモデルは含みません。** 利用者が用意した素材から、メニュー付きPrefabを生成します。

[English](README_EN.md) · [必要パッケージ名](Requirements.txt)

[ソース一式（ZIP）](AnywhereMMD-source.zip?raw=true)

## 公開版の状態

初期プレビュー版です。既存の分身生成・表示処理をもとに、素材指定式の生成画面を追加しています。
検証範囲は [VALIDATION.md](VALIDATION.md) を参照してください。全アバター・全ワールドでの動作保証はありません。

## 素材を設定する

1. UnityのProjectウィンドウで **Create → Anywhere MMD → Collection** を選びます。
2. 作成した設定アセットを選択します。Language / 言語で日本語とEnglishを切り替えられます。
3. 曲ごとに、曲名・音源・Humanoidダンス・カメラアニメーションを指定します。最大16曲です。
4. **Prefabを生成** を押します。生成先は `Assets/AnywhereMMD-Generated/Collection-…/Anywhere MMD.prefab` です。
5. 生成したPrefabをHumanoidアバターの直下に1つ配置します。ビルド時に、そのアバターから撮影用分身を生成します。

生成のたびに別フォルダーを作成します。元の音源・モーション・既存Prefabは変更しません。
曲を変更したら再生成し、アバターに配置した旧Prefabを新しいものと置き換えてください。設定済みPrefabの自動更新機能はありません。

### 対応する素材

- 音源：UnityにインポートしたAudioClip。生成したコピーを先読み・展開再生に設定します。
- ダンス：非LegacyのHumanoid AnimationClip。表情は元のブレンドシェイプ名との一致で対応します。
- カメラ：Transform／Cameraを動かすAnimationClip。
- VMDファイルを直接変換する機能はありません。事前にUnity用AnimationClipへ変換してください。

### カメラRig

カメラRig Prefabを空欄にした場合、クリップのパスは次の階層に対応している必要があります。

```text
Rig root
└─ Pivot
   └─ Camera
```

パスが異なる素材は、クリップのパスと一致するカメラRig Prefabを指定してください。
RigはTransformとCamera1個で構成し、全オブジェクトを有効にします。AudioListenerは生成時に除去します。
スクリプト、Animator、描画モデル、音源などを混ぜたRigは受け付けません。
Rigのルートに対するアニメーションにも対応し、身長補正は外側の別Transformで行います。
撮影カメラの有効状態・描画距離などはツールが設定します。
元のカメラとダンスは、同じ開始時刻・座標系を前提とします。音ズレの自動解析・補正は行いません。

## アバター側の設定

Prefab最上位の **Anywhere MMD Options** に、同期方式・解像度・表示距離・つかみ設定があります。
各Trackの **Anywhere MMD** には、元カメラの基準目線高（初期値1.5m）と画角・高さ補正があります。

- 同期型：本体FXの対応する衣装表示・マテリアル設定に分身が追従します。
- 非同期型：生成時の衣装を使い、対応するlilToon／lilSSRTマテリアルを分身専用コピーで固定照明にします。
- 通常のPhysBoneの揺れとコライダーを保持します。複数曲では共有できる部分を共用します。
- 共用する髪・服のつかみ操作は初期状態で省略します。本体と曲別に保持する指などの設定は変更しません。

## VRChat内のメニュー

メニュー名 → **曲選択 / Songs** と **表示設定 / Display**。

| 表示設定 | 映像 | 音声 |
|---|---|---|
| 全てOFF | 通常表示 | 通常再生 |
| Camera Only | VRChat撮影カメラのみ | 通常再生 |
| Local | 自分のみ | 自分のみ |
| Local + Camera Only | 自分の撮影カメラのみ | 自分のみ |

表示トグルは排他的です。曲を最初から再生し直すには、一度停止して選び直してください。
複数のCollectionを同時再生すると映像・音声が重なります。1アバターにつき1Collectionを推奨します。

## 制約

- PC用です。見る側でアバターのカメラが許可されている必要があります。
- 途中参加者への曲の再生位置合わせや、継続的な音声時計による補正は未実装です。
- 特殊なシェーダー、FX以外の着替え、独自スクリプトによる見た目変更は個別確認が必要です。
- 専用撮影空間を上空に配置しますが、そこへ侵入したワールド物体を完全に排除する方式ではありません。
- ビルド容量・PhysBone数はアバターと曲数に依存します。SDKで確認してください。
- 以前のAnywhere MMD／Dance Lounge版と同じコンポーネントGUIDを使います。別実装を同じプロジェクトへ重複配置しないでください。

## 同梱内容と素材の権利

公開物は設定UI、生成処理、分身・表示処理、専用の背景／画面シェーダーです。
第三者製パッケージ、楽曲、振付・モーション、ユーザーのアバターは同梱しません。
自分で使用・共有する素材については、それぞれの利用条件に従ってください。

利用ライセンスは現時点で未設定です。GitHubへの公開は、無制限な再配布・改変許諾を意味しません。
